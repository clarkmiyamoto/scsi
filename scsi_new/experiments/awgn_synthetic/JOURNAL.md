# awgn_synthetic — experiment journal

Newest first. Format and rules: [`../JOURNAL_TEMPLATE.md`](../JOURNAL_TEMPLATE.md).

Purpose of this experiment (from `data.py`): stress-test whether SCSI's EM loop recovers the
**full** ground-truth distribution, all modes included (default: an 8-mode Gaussian ring),
when warm-started on a deliberately poor single-Gaussian prior, under `y = x + noise`.

No sweeps or recorded outcomes exist in the repo yet, so there are no entries. Add the first one
with the template when you run something here.
